# Contributing

DFlow-AF is a research codebase. Contributions should preserve the distinction between exploratory hypotheses and validated results.

Before opening a pull request:

1. Add or update tests.
2. Record assumptions explicitly.
3. Do not commit third-party model weights or large MD trajectories.
4. Do not interpret predictor confidence as thermodynamic stability.
5. Preserve all-L/all-D mirror controls when changing chirality handling.
